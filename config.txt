========================================================================
| In order to compile nauty on systems which include a Unix-like shell
| (which includes MacOSX and Cygwin), you must first run the script
| "configure".  Usually this can be done with the command
|  ./configure
| 
| The configure script creates makefile and build/makefile, together with
| build/gtools.h, build/naututil.h, build/nauty.h and build/runalltests.
| Afterwards use "make" to compile tools into bin/ and libraries into build/.
| C sources and header templates are in src/; tests and fixtures are in test/.
| Configuration is required; the obsolete makefile.basic has been removed.
| See README for out-of-tree builds and uninstalled library usage.
| 
| Please notify Brendan McKay <brendan.mckay@anu.edu.au> of any problems
| with the configuration and of any hints you might have for other people
| with similar setups as you have.
========================================================================
